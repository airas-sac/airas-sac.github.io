# AIRAS website

Edit the AIRAS 2027 page content in `airas2027/index.md`.

Edit the root year-listing page in `index.md`.

GitHub Pages builds the Markdown files with the layouts in `_layouts/`.
The site styling and navigation behavior remain in `styles.css` and `script.js`.

Run a local preview with:

```sh
make serve
```

Run a one-time build check with:

```sh
make build
```
